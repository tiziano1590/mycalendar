# MyCalendar

A simple Python package that prints the calendar and highlights the current day.

## Installation

```bash
pip install -e .
```

## Usage

Run the calendar directly:

```bash
mycalendar
```

Or use it as a module:

```python
from mycalendar import print_current_month

# Print and highlight the current month
print_current_month()
```
